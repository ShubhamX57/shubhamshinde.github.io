Research

A rare silent failure in Bayesian diffusion analysis

MSc dissertation · University of Bristol · supervised by Dr Andrew McCluskey · 2026

kinisi is an open-source Python library that estimates how fast atoms and ions move by fitting the mean squared displacement from molecular dynamics. The fit needs the inverse of a covariance matrix that is itself estimated from the trajectory, and very occasionally it returned a diffusion coefficient wrong by up to three orders of magnitude, with no warning.

  • Ran 64,000 random-walk fits with a known answer; 14 failed, each reproducible from its seed.
  • Showed the cause is sampling noise in the long-lag variances: more particles (64 to 16,384) cut non-positive-definite covariance matrices from 90.5% to 0.5%.
  • Found that standard diagnostics such as the condition number cannot reliably detect the failures, but that the direction of the instability matters.
  • Developed an independent check, comparing the Bayesian estimate with an ordinary least squares slope, that flags all 13 covariance-driven failures at a 1.5% false-alarm rate.

Presented at RSECon26. A pull request to kinisi is open and a paper is in preparation. Code

qens: Bayesian analysis of neutron scattering data

With ISIS Neutron and Muon Source · supervised by Gøran Nilsen and Dr Andrew McCluskey · 2025–2026

Quasi-elastic neutron scattering shows how atoms and molecules move inside materials, but its data is usually fitted one slice at a time. qens reads ISIS NXSPE files and fits physical models across all momentum transfers at once, using MCMC with convergence checks so every result comes with an uncertainty, behind a simple interface for facility users.

Projects

phasecover: periodicity searches in gappy telescope data

Telescopes in low Earth orbit lose sight of their target every orbit, so standard tests can "detect" the observing pattern instead of the source. phasecover tests photon events against what an unmodulated source should produce under the real observing windows, cutting false detections from 100% to 0% in Monte Carlo tests while still finding a weak 3% signal. Built on Astropy, with FITS reading, a command-line tool and 19 tests.

GitHub repository

nxcat: catalogue for neutron and X-ray data

Ingests NeXus/HDF5 experiment files into PostgreSQL with metadata validation, with a FastAPI search API and a React web app. In its plain-English search, a language model may only propose a filter, which is validated and confirmed by the user before it runs. 98.5% backend test coverage and a one-command Docker setup.

GitHub repository

Accelerated liquid-crystal simulation

Took a Lebwohl–Lasher Monte Carlo simulation through several implementations, from pure Python and NumPy to Numba, Cython, OpenMP and hybrid MPI, with tests to check that every optimisation preserved the model's behaviour.

Distributed Higgs analysis

Scaled the ATLAS Open Data Higgs to four-lepton analysis across Docker workers coordinated through RabbitMQ, with retries, a dead-letter queue, checkpointing and Prometheus metrics, reproducing the reference result.

arxiv-rag: question answering over research papers

A language model that may only answer from passages retrieved from 204 arXiv papers, with hybrid search, reranking and a check that every quoted citation matches its source. On 76 test questions, reranking raised MRR@10 from 0.80 to 0.96.
